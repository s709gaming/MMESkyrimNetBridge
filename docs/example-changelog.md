# 🥛 MME Extensions v1.5.2 beta Changelog

> Example draft: feature descriptions do not imply that every feature has passed in-game testing.

## 🌟 Major Features

- 👙 **Individual Armor Modifications:** Erotic upgrades are now tracked per armor item instead of by armor name like the original MME. Every outfit remembers its own naughty little secrets!

- 📚 **Skyrim.Net Milk Maid Knowledge Pack:** Moved Milk Maid lore into a dedicated knowledge pack, helping AI NPCs understand what Milk Maids are. Now everyone *might* finally know where Skyrim's milk comes from!
