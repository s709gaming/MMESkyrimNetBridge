# Personal entry titles

- Use the pencil beside an entry to rename it. Choose **Use title**, then **Save Changes**.
- Titles can contain 1–80 characters on one line. They appear as plain text and do not change narration, messages, gameplay or internal entry IDs.
- **Cancel** leaves the title alone. **Reset title** stages a return to the supplied title in your selected language; Save Changes applies it.
- **Reset Edited Text** affects text only. Personal titles are kept.
- Custom titles stay exactly as entered when the interface language changes. Supplied titles use the selected language.
- Presets include text and titles. Merge keeps existing personal titles and adds missing ones. Replace applies preset titles and resets names absent from that preset. Replacing from an older preset without titles restores supplied titles.
- Existing personal files remain supported. Titles use an optional `titles` map in the same personal file; they never enter the runtime template snapshot.

Install the dashboard and native DLL from the same package. Older native backends can still edit text, but the pencil is disabled until the backend supports titles.
