# Framework and legacy archive

This directory holds inactive reference material only. Active source, build
configuration, dependencies, compiled scripts, and release archives remain at
the project root.

- `SPID/` documents the SPID integration boundary. The active
  `MMEAlert_DISTR.ini` remains at the project root; no duplicate SPID framework
  package was found to move here.
- `CommonLibSSE-NG/` documents the CommonLib archive boundary. The only checkout
  found is required by `CMakeLists.txt`, so it remains active under
  `extern/CommonLibSSE-NG` rather than being archived.
- `LegacyProjectBackup/` contains verified obsolete backup and superseded test
  artifacts, preserving their original names and relative structure.
